# 运动达人 V0.2｜MediaPipe 引入与验收门

记录日期：2026-10-13

## 目标和边界
基于用户提供的乒乓球动作纠正方案，先验证「真实视频→33关键点→可追溯数据→骨骼视频→检测质量」最小闭环。不得把姿态关键点直接等同于专业纠错。保留既有 V0.2 任务优先级；此模块是候选技术实现，不声称替代现有原型或施工单。

## 已提交的实现
- `movement_v02_pose.py`：本地视频输入；逐帧 MediaPipe Pose；关键点含可见度 JSONL；骨骼叠加 MP4；右肘二维角度（仅在关键点达到可见度阈值时）；摘要包含有效帧比例。
- 不做默认 1280x720 强制重采样，不做会破坏颜色信息的灰度化；保留原始帧率和时间索引。
- 未实施时序分类、击球检测、重心推断、自动打分、自动纠错；这些都需有独立证据和验证集。
- 对左右持拍手、机位、遮挡、视频质量、许可和隐私的要求留作后续验收门，不用假数据填充。

## 运行
```bash
python -m pip install mediapipe opencv-python numpy
python prototypes/movement-v02/movement_v02_pose.py INPUT.mp4 --output-dir OUTPUT
```
