# 陪你读书｜V0.1 可行性与开发执行基线
版本：0.1.0（2026-10-12）｜状态：方案已建立，代码/云端发布未验收
归属：零一空间第三项目（独立于「零一空间研究」「动起来」）；主线：可打开、可听、可复现的云端原型机。

## 1. 产品假设
优先服务：①尚未识字的儿童及其监护人；②因视力或其他原因不便阅读的老年人。其他用户为非首要目标。以中国四大名著为第一批作品目录，**先完成《西游记》第一回的短段落**；其余三部不作为V0.1交付阻塞项。儿童模式不得直接把未审校的原著当作适龄内容；老人模式突出大按钮、清晰人声、可关闭音乐、进度恢复。用户不必注册即可试听公开内容。

## 2. V0.1交付边界（必须能实际听到）
- 作品/章节/段落与来源版本记录，明确原文和儿童改写文本。
- 至少两种合法可用的标准TTS声音，章节短段落可播放、暂停、调速、刷新后恢复进度。
- **音乐为必选研究模块**，而非必须强制播放：A 文本→场景/叙事功能→生成音乐；B 用户提供有权使用的音乐→剪接/淡化/均衡/自动压低伴奏→配合朗读。另有纯人声基线。三版本可A/B试听、独立调节背景音量；输出来源、参数、模型版本及可重复的混音清单。
- 私人家庭声音（包括逝者声音记忆）保留数据接口与独立授权/审核门；**不阻塞首个公开试听**。不以家属身份自动代替法律授权；禁止未经审核公开仿声和冒充实时本人。
- 公开HTTPS地址、真实浏览器播放验证、音频可听的人工试听记录、成本测量；无公开读回不得标记已发布。

## 3. 架构（云端优先，开源优先，模型可替换）
Web PWA/静态前端 → API/任务队列 → 文本目录/权利清单 → TTS适配器 → 音乐生成适配器/用户授权素材 → FFmpeg确定性剪接/混音/ducking → 对象存储缓存/CDN → 浏览器播放。
元数据：work_id, edition_id, passage_id, text_hash, source_url, rights_basis, jurisdiction, audience_mode, voice_model, voice_license, music_source, music_license, generation_prompt, model_version, mix_recipe, output_hash, reviewer, release_status。
建议初期用对象存储+小型数据库+按需GPU；不得长期常驻GPU而未测算成本。模型和权重许可证逐项审核，开源代码不等于权重可商用。
候选：CosyVoice（中文TTS/声音适配，核验具体权重许可）、ACE-Step 1.5（音乐生成与参考音频编辑，核验当前版本许可与性能）、FFmpeg（确定性剪辑混音）、Demucs（仅在授权允许且确有需要时分离）、MusicGen仅作许可允许范围内对照，**不得默认用于收费服务**。
文本优先从维基文库等来源获取，但须逐版本核实：原著、校注、改写、插图和译本分别判断权利。背景音乐生成/改编同样要记录授权。

## 4. 音乐研究方法（不可跳过）
固定同一段文本、同一TTS、同一响度，制作三条样本：S0无配乐、S1模型生成、S2用户授权音乐重新编排。场景级而非逐句生成；允许沉默。对比：语音可懂度、音乐遮蔽、叙事贴合、听觉疲劳、儿童/老人可用性、生成耗时、每分钟成本。人工盲听与主观记录必须与自动检测分开；不得仅凭模型打分宣布好听。未经许可的参考音乐不得公开发布衍生音频。
优先实现 FFmpeg 的音量包络、crossfade、ducking、响度归一；模型生成可异步处理和缓存，避免重复计算。

## 5. 三博士职责与执行真实性
- C博士：项目主责/产品边界、架构、许可风险门、任务拆解、集成验收、发布与成本审计。
- Q博士：前端作品目录、播放器、儿童/老人两模式、音乐A/B切换、上传与授权界面、浏览器测试。
- D博士：开源模型与许可证核查、TTS/音乐生成可复现实验、FFmpeg混音流水线、GPU成本测量、服务接口。
**任务指派不等于模型已经执行**。每次提交必须记录任务ID、调度人、真实执行者、模型/工具调用证据、提交SHA、测试日志、人工验收者。若Q/D提供方不可用，状态写 BLOCKED_PROVIDER，不得冒名由C或GitHub连接器代做后归功Q/D。
原有A01/B01不转移、不重命名、不覆盖。第三项目采用独立分支和Issue，先不接入会干扰既有主线的自动定时工作流。

## 6. 执行闭环与里程碑
R00 许可/资源与技术基线 → R01 页面+合法文本+标准TTS播放 → R02 三种音乐版本生成/上传与混音 → R03 云端公开发布/读回 → R04 家庭声音授权与私人试读（后续门）。
每项状态只用 TODO / IN_PROGRESS / BLOCKED / REVIEW / ACCEPTED，只有实际验证并形成证据才可ACCEPTED。提交→静态测试→真实浏览器→人工试听→公开URL读回→成本记录→验收。阻塞问题保留原编号直至闭环。

## 7. 风险与费用
高风险：原著具体版本/儿童改写版权、音乐参考素材的改编权、声音克隆及逝者权益、儿童隐私、文学文本与朗读错误；中风险：长篇音频连贯性、GPU推理费用、音频缓存/分发。优先预生成标准音频，私有声音按需生成。试验性支出目标上限 €50/月（非报价或成本保证），超额需单独确认；记录GPU秒数、每分钟音频成本、存储和流量。

## 9. RW-04 家庭声音学习｜优先级提升为V0.1关键实验（2026-10-12）
修订：S0为标准纯AI声音基线；**新增F0：经权利审核的参考声音→特征分析→家庭声音试读**。S1/S2音乐仍是V0.1核心研究，F0与音乐模块可以交叉组合，不再把家庭声音学习一概延后。首轮需至少一份有权使用的参考样本、同文本标准声/参考声对照试听、分析报告；若真实家庭录音未提供，可先使用明确授权的测试声音，不得伪称家人声音已通过。
开源候选与分工：
- CosyVoice（官方 FunAudioLLM/CosyVoice）：中文/方言/zero-shot参考声音，主候选。
- IndexTTS 2/2.5（官方 index-tts/index-tts）：音色与情绪参考分离、语速/韵律控制，对照候选，核查实际权重授权。
- OpenVoice V2（官方 myshell-ai/OpenVoice）：音色迁移、节奏/停顿/语调风格控制，对照候选，MIT声明须复核。
- Chatterbox Multilingual（官方 resemble-ai/chatterbox）：23语种、参考音频、声音水印，跨语言对照候选。
- 韵律提取：librosa/Parselmouth等按许可评估；openSMILE开源版本明确非商业限制，未来正现金流部署不可直接默认可用。
**分析报告**：参考录音质量/时长/噪声、基频F0分布、语速/停顿/重音/音量包络/音色描述、语言/口音的人工核查、可信度与局限。特征分析≠能够准确复制真人独特节奏；分别评价音色相似度、节奏相似度、清晰度和长篇一致性。
安全与许可门：参考声音必须是本人同意或具有可核查的合法授权/权利基础的素材；播音员声音的公开可听不代表允许克隆，未获授权只可分析不涉及身份复制的通用声学特征。逝者声音记忆允许作为独立合法场景研究，但需审查生前意愿、相关权利与地域法律，禁止冒充实时本人；默认私人保存、可撤销删除、合成标识和访问控制。未经权利审查不得生成可识别的第三方声音试读。
执行：C博士许可与验收；D博士参考声音分析+多引擎实验；Q博士上传/试听/授权界面。任务实际状态依模型调用与测试证据更新。
