## 统一施工优先序（先组装，后精修）
### P0｜用户可见的整体场景
**A01 运动达人：** 选择目标/身体条件/环境 → 选择全身训练计划 → 连续教学示范与跟练 → 训练记录 → 可选视频对照 → 反馈/下一次计划。真实人体与完整动作优先于孤立肢体；已有MediaPipe/OpenSim/wger证据作为可替换能力，不冒充已集成。
**B01 堪舆先生：** 先生接案首页 → 问题分类（失物、吉凶、前程、婚姻、求子、择日、住宅等）→ 选择传统方法及输入所需资料 → 演算/来源解释 → 追问与保存案例。住宅平面图/环境计算属于「住宅专题」。没有可验证依据的预测必须显式标为传统解释、未证实；涉及生育、健康、财产不代替专业意见。
**C01 陪你读书：** 作品/段落选择 → 可听朗读 → 儿童/老人模式 → 进度/音频研究。原工单 #10–#15 不变。

### P1｜独立测试与双盲验证
1. 发布前：静态测试、真实浏览器、手机基本交互、公开HTTPS读回；至少一名未参与实现的验收者测试。
2. 预先冻结用户任务和通过标准；测试者不看实现提示，开发者不得根据测试中答案即时改动评分规则。
3. 对教学体验采用任务盲测（能否独立完成场景）；对传统预测声称的准确性采用预测者与评分者信息隔离、预注册样本/基线/失败记录，不能用几例演示证明预测有效。
4. 不适用双盲的工程测试标注为独立功能测试，不虚称双盲。

G0 旧任务/资料核对 → G1 整体流程可操作 → G2 成熟能力真实接入或明确占位 → G3 独立测试 → G4 CI/PR审查 → G5 主分支Pages发布并外部读回 → G6 用户体验反馈与台账归档。任何一门未过不得 ACCEPTED。
