# 看世界｜项目说明与原型记录

建立日期：2026-10-15
仓库：foxlongfei/zero-one-workbench
开发分支：watch-world-prototype
原型页面：portal/watch-world.html
状态：开发原型，未合并、未部署到正式 Pages，未完成真实直播源验收。

## 目标
从个人真实使用出发，做一个手机、电脑、平板可用的免费公开直播入口；未来可为父母的普通可安装第三方应用的 Android TV BOX 提供简洁模式，但暂不开发 TV BOX 版本。体验要求：少而精、打开就看、干净、避免购物频道、避免重复与失效资源。

## 内容
优先：太空与科学、世界城市与风景、自然与动物、时装与模特、音乐影像（MTV 风格）；后续可纳入有公开播放许可的电视/IPTV。可以与现有独立应用「听世界」搭配，例如视频静音并播放古典音乐；第一版不强行集成双播放器。

## 实施约束
1. 优先成熟的开源播放器（浏览器原生视频、后续 hls.js/Shaka Player），不从零造轮子。
2. 目录只接受来源可追溯、具有公开访问依据的官方资源；能公开观看不等于可嵌入或再分发。
3. 先去重（频道 ID、规范化 URL），再检查 URL 有效性、真实播放、格式、地区限制和可用时间；HTTP 200 不等于视频可播放。
4. 自动化定期复查并记录 last_checked、结果、失败次数；连续失败下架或转官方入口，恢复后再加入。初版尚未实现自动检查，不得声称已实现。
5. 屏蔽电视购物类频道；购物节目识别另需节目级规则，不得夸称完全过滤。
6. 个人端优先，不引入账户、广告、社交、复杂推荐；父母电视端在内容与稳定性验证后再适配遥控器。
7. 不影响原 A01 运动达人、B01 堪舆先生、C01 陪你读书的未完成主线。

## 当前实际代码
- portal/watch-world.html：响应式界面、播放器区域、分类搜索、重试、静音和官方跳转。
- portal/watch-world.js：加载 JSON 目录、去重、筛选、播放失败提示与官方入口回退。HLS 非原生播放需要未来正式引入开源播放器依赖；现阶段未引入，不能宣称跨浏览器 HLS 可用。
- portal/watch-world-sources.json：五个官方站点入口；无未经实测的 streamUrl，因此暂不能在站内直接播放。

## 待验收的明确任务
- 逐条验证官方地址真实可达及可嵌入权限；不允许用官网存在代替直播可播放。
- 选定可合法嵌入的 HLS/DASH/官方 iframe，接入开源播放器并实测至少数个直播。
- GitHub Actions 定时检测：超时、媒体播放有效性、去重、失败降级、更新时间、日志与目录输出。
- 在手机和电脑浏览器验证，形成测试记录。
- 发布公开可访问原型，读回验证后再提供正式体验链接。
