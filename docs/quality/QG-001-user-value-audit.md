## 立即生效的验收规则
1. 后台运行次数、参数数目、文件数、提交数不计作用户价值指标。
2. 每次改动记录：旧版基线、用户任务、预期改善、对照数据、回退条件。
3. 测试分层：代码/CI通过、已部署、浏览器实测、用户任务成功、独立复核，逐项列证据；不得互相替代。
4. 不得用三博士共识证明外部真实性。堪舆计算一致性与预测有效性分别评价。
5. 无可证明收益时，默认不继续增加参数；保留可回退的旧版本。
