# 动起来｜人体—场景—力学关系模型 V0.1

更新时间：2026-09-26 17:38 +08:00

状态：辅线有效增量；不计入 M01—M04 主线完成数。

## 核心链
HUMAN → SCENE → RELATION → FORCE → MOTION → EXERCISE → TRAINING_ADAPTATION

人体是主体；场景提供条件；人与物建立关系后才出现具体力学问题；动作是在这些条件下可发生的一种运动组织。器械不是运动前提，只是改变支点、约束、阻力、稳定要求和力矩的工具。

## SCENE 最小字段 V0.1
- body_posture：站 / 坐 / 跪 / 仰卧 / 俯卧 / 侧卧 / 俯身 / 支撑 / 悬垂
- support：地面 / 墙 / 椅凳 / 单杠 / 双杠 / 其他环境支撑
- equipment：无器械 / 自由重量 / 弹力带 / 绳索 / 固定器械
- resistance_source：重力 / 自重 / 弹性 / 配重 / 外力
- environment：室内 / 户外等条件标签；不得直接推导训练效果

“无器械”不等于“无环境”：身体质量、重力、地面/空间与身体节段之间的作用仍然存在。

## 交互顺序
1. 人体
2. 场景 / 硬件条件
3. 在该条件下可发生的动作
4. 运动面 / 轴与关节运动
5. 阻力、力矩、向心 / 离心 / 等长
6. 主动 / 协同 / 稳定 / 拮抗关系
7. 呼吸、ROM、训练目标与适应

## 反固化约束
不把健身房、器械、装备、术语或流行包装自动等同专业；也不把徒手、户外、简单、传统或冷门自动等同更真实。专业判断回到证据、人体—环境关系与长期实践。
