## MAIN 2｜堪舆先生 V0｜EXECUTING
**用户要看到：一个可以直接问现实问题的先生。**
打开页面 → 直接说问题 → 系统追问缺失现实信息 → 自动选择当前会的方法 → 实际运行 → 给结果/过程/边界 → “为什么/来源”可展开。

- Z05、二十四山、问题路由器、叠加模型：全部降级为 INTERNAL TOOLS。
- 第一版不要求全能；至少完成一个现实问题端到端运行。
- 第一验收：用户无需知道 Z05 / RULE_TABLE 等术语即可完成一次实际问答。
