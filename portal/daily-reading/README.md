# 每天读世界 · V0.2 原型

- 私人日报：默认每日一篇，最多三篇；年代不限，独立思想与完整原文优先。
- 手机与电脑：`index.html` 响应式排版；夜间模式、字号、收藏、邮件链接分享、打印。
- 本次：5篇真实文章的原创导读、作者和原文入口；不是全文译文，不冒充自动采集已运行。
- 下一步：RSS/Atom来源采集→去重与全文核验→私人翻译→每日一期。提取引擎优先 Mozilla Readability（Apache-2.0），不自造复杂采集器。
- 版权边界：公开 GitHub Pages 只放元数据、原创导读和许可允许的正文；个人受版权保护的全文与译文不进入公开仓库。
- 邮件按钮目前使用 mailto 打开用户邮件客户端；自动邮件投递需要发件账号授权。
- 当前独立目录：`portal/daily-reading/`，不修改其他项目或代理任务。
