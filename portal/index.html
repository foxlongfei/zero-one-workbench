运动达人 V0

目标：先让一个完整的人站起来，再把训练、动作、视频分析和反馈能力挂到他身上。

当前整机策略：完整人体直接采用成熟开放人体底座；旧右上肢与肱二头肌工作降级为插件。

第一台原型要做到：完整3D人体可旋转/缩放/点选 → 直接说“我想……” → 按目标、时间、场地/器械和反馈给可执行训练 → 继续调整。

后台底座：BodyParts3D / Human Atlas + OpenSim + 成熟姿态/动作捕捉方案。你不需要理解这些名字。

堪舆先生 V0

目标：先让一个先生坐在那里，你直接说现实问题，他负责追问和调用工具。

当前整机策略：Z05、二十四山、叠加模型、历法/地图/方向等全部成为内部工具，不再让你操作研究编号。

第一台原型要做到：直接说“我想……”或给户型图、照片、视频 → 自动追问必要现实信息 → 调用可用方法/工具 → 给建议、原因、边界，来源可展开。

原则：第一版可以不会所有方法，但不能用假结果填空。
