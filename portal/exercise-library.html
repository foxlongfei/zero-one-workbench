第一层｜共同的人体坐标系

先建立所有动作共用的空间语言，再学习单个动作。专业中文术语为主，英文原词保留用于检索和对照；解释尽量直白，但不牺牲准确性。

标准解剖姿势 Anatomical position→ 方位 Direction→ 三个运动面 Planes→ 三条轴 Axes→ 关节运动 Joint motion→ 肌肉与收缩 Muscle action
三个运动面 × 运动轴
矢状面Sagittal plane ｜把身体分为左右；典型动作：屈曲/伸展 Flexion/Extension；主要绕额状轴（左右方向的轴，mediolateral axis）运动。额状面Frontal plane / Coronal plane ｜把身体分为前后；典型动作：外展/内收 Abduction/Adduction；主要绕矢状轴（前后方向的轴，anteroposterior axis）运动。水平面Transverse plane ｜把身体分为上下；典型动作：内旋/外旋 Internal/External rotation；主要绕垂直轴（longitudinal/vertical axis）运动。

这是基础坐标，不是“所有动作只能属于一个平面”的规则；真实复合动作常同时跨多个平面和轴。

肌肉工作语言

主动肌 Agonist/Prime mover：主要产生目标动作；拮抗肌 Antagonist：在该动作关系中产生相反作用；协同肌 Synergist：协助完成动作；稳定肌 Stabilizer：控制不希望发生的运动。

向心收缩 Concentric：肌肉产生张力并缩短；可理解为“把负荷拉上来”。 离心收缩 Eccentric：产生张力同时被拉长，更像“带着刹车把负荷放回去”。 等长收缩 Isometric：产生张力而整体长度变化很小，像“稳住不让它跑”。比喻用于理解，正式判定仍以具体动作和关节力矩为准。

参考学习层，不参与 REP_GATE。动作数据与动图来自 hasaneyldrm/exercises-dataset；中文说明直接读取其 zh 字段。3D人体部分采用可旋转的公开模型窗口；肌肉结构与骨骼结构独立展示。向心/离心和阻力方向目前只在有可靠映射时显示，避免把“目标肌群”直接当成收缩类型。

知识结构 V0.1｜人体坐标系怎样长成完整工具

核心不是动作列表，而是一张关系网：身体区域 → 骨骼 → 关节 → 运动面/轴 → 关节运动 → 肌肉/肌腱 → 动作阶段 → 收缩方式 → 训练目标 → 恢复与安全。

A｜空间坐标
标准解剖姿势、上下/前后/内外、矢状/额状/水平面、三条运动轴。
B｜结构地图
骨骼、关节、肌肉、肌腱；肌肉记录起点 Origin、止点 Insertion、跨越关节。
C｜运动语言
屈/伸、外展/内收、内旋/外旋、旋前/旋后、肩胛运动等；每项关联平面与轴。
D｜肌肉角色
主动肌、协同肌、稳定肌、拮抗肌；角色随动作和阶段变化，不给肌肉贴永久标签。
E｜动作时间轴
起始位 → 发力阶段 → 转换 → 回程；标记向心/离心/等长、ROM、阻力方向、呼吸与常见代偿。
F｜训练处方入口
从“我要练哪里/什么能力”进入：力量、肌耐力、活动度/拉伸、技术、恢复。
G｜身体问题入口
从部位/症状进入：位置、诱发动作、感觉类型 → 低风险恢复方法 → 停止条件/专业评估；不把酸痛自动诊断成某块肌肉。
H｜学习层
专业中文 + 英文原词 + 🔊发音 + 简明解释/比喻 + 自己身体上的触摸与动作验证。
首个完整样板｜肱二头肌—肘关节—前臂

目标：不是做一张“弯举卡”，而是贯通 肱二头肌 Biceps brachii → 起止点 → 肘屈与前臂旋后 → 相关平面/轴 → 肱肌/肱桡肌等协同关系 → 肱三头肌等拮抗关系 → 弯举动作阶段 → 向心/离心 → 呼吸 → 力量/耐力 → 拉伸/放松 → 常见代偿与安全边界。

当前状态：结构已确定，具体解剖和动作字段必须逐项来源校订后才进入“已确认”；不从现有动作数据集自动推断。

数据对象｜以后每条知识至少知道自己是什么

BodyRegion 身体区域 ｜ Bone 骨 ｜ Joint 关节 ｜ Muscle 肌肉 ｜ Tendon 肌腱 ｜ Motion 关节运动 ｜ Exercise 动作 ｜ Phase 动作阶段 ｜ TrainingGoal 训练目标 ｜ RecoveryMethod 恢复方法。

关系示例：Muscle --crosses→ Joint、Motion --occurs_in→ Plane、Exercise --contains→ Phase、Phase --uses→ ContractionType。这使以后可以正向“我要练肱二头肌”，也可以反向“我的肘前侧不舒服”。

学习路径｜以后每个动作按同一顺序展开

结构：骨骼 → 关节 → 肌肉/肌腱 → 起点 Origin / 止点 Insertion；空间：运动面 → 运动轴 → 关节动作；功能：主动肌 → 协同肌 → 稳定肌 → 拮抗肌；过程：起始位 → 向心/离心/等长 → 呼吸 → ROM → 常见代偿；实践：自己做 → 触摸/感受 → 对照模型 → 再理解。未核实内容不自动补齐。
