# 动起来 V0.2 — 完整成熟系统部署入口

## 当前交付状态
这是**可执行的完整上游部署入口**，不是已上线的用户原型机。尚未在可公网访问的 HTTPS 主机上完成部署、训练保存/读回及手机端验收，不得标记 V0.2 已交付。

## 原则
采用 [openGym](https://github.com/DuarteSantos8/openGym) **完整原版**，不复制、删减、改写其动作管理、训练计划、组数记录、历史数据、离线及账号功能。现有 MediaPipe 原型作为独立实验模块保留，不替代完整训练产品。

## 执行
在有 Docker Compose 的 Linux/macOS 主机：
```sh
bash deploy/movement-v02/bootstrap.sh
```
脚本会拉取完整上游仓库、创建其 .env、拉取预编译容器、启动完整 web + API，并检测 /api/health。默认本机地址 http://localhost:8080。

公网及手机多设备登录需要 HTTPS 域名，并按照上游 [self-hosting 指南](https://opengym.ch/docs.html) 配置 RP_ID / ORIGIN / 反向代理。不得直接把 localhost 配置作为公网 WebAuthn 服务。

## 版权与数据
openGym 应用 AGPL-3.0；其动作媒体图片/GIF 不自动继承代码许可，必须单独核查权利后再对外发布。不要把受限媒体复制进本仓库。持久化数据位于上游实例数据目录，需单独备份。用户测试须检查新增训练、刷新后读取、离线恢复、CSV/备份及手机端。
